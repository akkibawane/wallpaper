## ?? Key Features

- **??? Dual Orientation Switcher**: Seamlessly toggle between Desktop (16:9 Landscape) and Mobile (9:16 Portrait) wallpaper viewports.
- **?? Dynamic Themes**: Customize accent themes, blur intensity, and dark/light modes on the fly.
- **?? Curated Categories & Search**: Browse Minimalist, Space & Cosmic, Cyberpunk, Nature Scenic, Abstract Art, Architecture, or search custom keywords.
- **??? High-Fidelity Preview Modal**: Test wallpaper appearance on simulated desktop and mobile device frames before downloading.
- **?? Local Favorites System**: Save your favorite wallpapers with persistent browser storage.
- **? Fast Image Loading**: Responsive lazy loading and blur-hash placeholders.

## ?? Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/akkibawane/wallpaper.git

# Navigate into the project folder
cd wallpaper

# Install dependencies
npm install

# Run development server
npm run dev
```

---

## ?? Production Build

```bash
# Build production bundle
npm run build

# Preview build locally
npm run preview
```

---

## ?? Deployment

Automated deployment is configured via GitHub Actions in [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml). Pushes to `main` automatically build with Vite and publish to GitHub Pages.
